Zomato Restaurant Data Analysis Dashboard (Excel Project)

Project Overview:
This project presents an interactive Zomato Restaurant Analysis Dashboard built in Microsoft Excel.
It analyzes restaurant data across cities, countries, cuisines, ratings, pricing, and services like online delivery and table booking.

Objectives:
- Analyze restaurant distribution across cities and countries
- Understand rating patterns of restaurants
- Analyze restaurants by price bucket
- Identify availability of online delivery and table booking
- Track restaurant openings by month
- Build an interactive dashboard using slicers

Tools & Features Used:
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers (City, Month, Price Bucket)
- Data Cleaning and Formatting
- KPI Cards and Dashboard Design

Key KPIs:
Total Votes: 1,496,450
Total Restaurants: 951
Total Cities: 141
Total Cuisines: 182
Total Countries: 15
Average Rating: 2.89

Dashboard Insights:
- Top cities with highest number of restaurants
- Restaurants grouped by average rating
- Restaurants categorized by price bucket
- Percentage offering table booking and online delivery
- Restaurants opening trends by month
- Average cost for two for top restaurants

Interactive Filters (Slicers):
- Month Name
- City
- Price Bucket

Data Preparation Steps:
1. Cleaned raw Zomato dataset
2. Removed duplicates and null values
3. Standardized city, country, and cuisine names
4. Created calculated columns for price buckets and rating groups
5. Built pivot tables and dashboard
